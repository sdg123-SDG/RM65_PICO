# 遥操数据记录

用 `start_real_trial.bat` 启动遥操，正常结束或程序返回后，会从该次已有的传输日志自动导出 CSV 到 `logs/real/datasets/`。每次会话各生成一个文件，原始 JSONL 日志仍保存在 `logs/real/transport_logs/`。

CSV 每行代表一条关节反馈或一次夹爪命令发送事件：

- `timestamp_unix_ns`：事件发生时的 Unix 时间，单位纳秒；`elapsed_s` 是相对于该次数据首条事件的秒数。
- `joint_1_deg` 至 `joint_6_deg`：控制箱返回的关节角，单位度，已换回控制箱关节符号。
- `x_m,y_m,z_m,rx_rad,ry_rad,rz_rad`：根据实测关节角，用现有 VDO 机械臂模型计算的控制箱末端位姿；位置单位米，欧拉角单位弧度。`pose_source=fk_measured_joints` 标明数据来源。这是模型计算结果，受模型精度及现场工具坐标影响。
- `gripper_command`：`1` 表示这一行发生了一次夹爪命令的本机发送；`0` 表示这一行没有发送夹爪命令。它不是夹爪开合位置，也不表示控制箱已确认或夹爪已动作。
- `event` 区分关节反馈与夹爪发送。夹爪事件行使用最近一次关节反馈计算的位姿，`state_age_s` 表示距该反馈的秒数；若命令发生时尚无反馈，关节与位姿留空。

反馈频率随控制箱实际返回情况变化，CSV 行间隔不固定。实机连接中断、窗口强制关闭等情况可能使自动导出未完成；原始 JSONL 可在之后手动导出，例如：

```powershell
cd E:\SDG-VLA\RM65_PICO\experiments\vr_teleop_rm65_pico_sim
E:\SDG-VLA\RM65_PICO\.venv\Scripts\python.exe .\export_teleop_data.py .\logs\real\transport_logs\latest_会话文件名.jsonl
```

导出不会覆盖已存在的 CSV。记录程序只读取已落盘的遥操日志，不向控制箱发送额外查询或控制命令。
