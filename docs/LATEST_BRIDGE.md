# 当前最新目标桥接

本文件描述 2026-10-21 综合审查后的实现；历史故障与检查范围见 AUDIT_COMPREHENSIVE_20261021.md。

入口 `start_real.bat -NoGripper` 使用 LatestBridgeServo。保留原生 PICO 输入、位置 IK、关节符号约定、实时起点与原生独立保护；不自动回零、不自动回基准、不读取或驱动夹爪。

## 通信与数据所有权

一个线程独占 TCP 收发；输入/模型只覆盖容量为1的最新目标，不保存运动 FIFO。原生状态采样只读通信模块快照，不再将旧缓存写回。接收器处理分包和同一行多个对象；畸形对象与控制器错误文本留痕，不当作有效反馈。

高精度 perf_counter 调度，每次写入完成后至少等待20ms再选下一条指令；不突发追赶错过的周期。因此实际频率可能低于50Hz，不能称硬实时。发送预算10ms，部分写入必须补齐或关闭连接，不能截断后继续下一条。

该机运动时只发送 follow=false 的 CANFD，使用已验证存在的 joint_state 更新实测关节；非运动时查询完整状态。每次最多一个未完成只读查询，150ms无回复后释放槽并重试状态；附加诊断无回复会禁用本会话附加诊断。运动和保持指令不因查询超时而重发。新鲜反馈时限仍为配置的0.5s。

收到禁用轴/轴错误将阻止继续运行，但运动中的 CANFD 反馈不含新鲜使能、sys_err 或位姿；不可宣称全部内部状态持续可见。

## 松手、暂停与退出

松手撤销目标，用当前实测角低速movej退出透传。只在保持窗口内处理movej应答或该机实际返回的轨迹完成消息；需随后至少3个样本、至少90ms、与目标不超过0.05度、样本波动不超过0.01度，才确认稳定。接受/完成等待最多3秒，首次接受后稳定等待最多3秒。重复应答不延长期限。

保持期间同时冻结模型和硬件跟随；完成后必须观察实际有效Grip释放，重新握持重新取起点。协议错误暂停也遵守此要求。CLI stop/pause锁住跟随并请求保持，resume只解除操作暂停，仍需释放再握持；该软件保持不等同于物理急停。

每秒3次协议错误、反馈过期、保持失败、轴异常、网络/日志故障继续按故障处理，不自动重连或恢复运动。同一通信对象不允许二次启动，需退出后新开会话。

正常退出使用同一输出模块确认保持。保护进程通过PID/地址/随机会话标识/时间匹配的原子退出记录跳过重复恢复；异常退出仍保留一次原生恢复流程。独立保护日志保存到 logs/real/guard_<pid>_<token>.log。

## 记录和验证

每轮日志为 logs/real/latest_*.jsonl，包含peer、收发事件、关节反馈、保持事件、协议暂停及错误；带wall_time_ns和perf_counter_s。写盘由有界独立线程负责，故障明确暴露。回环测试日志放临时目录，与现场记录隔离。
