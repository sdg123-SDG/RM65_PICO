新增 frames_sent、手柄/实测位移和阻挡原因；异常写入 logs/real/last_error.json 并在 XR 会话中追加 error 事件。底层 launch_rm65_box_cli.py 修正了异常退出仍 os._exit(0) 的问题；安装补丁为 patches/vdo-exit-status.patch。启动失败现在不再伪装成成功退出。原 launch_rm65_box_real.py 文件未改。

## 改了哪些关键点

1. 新入口每次启动自动只读查询硬件，并核对型号、工具/工作坐标、使能/错误、限位。未识别型号、缺少必要查询、非零工作坐标、错误或掉使能时拒绝进入遥操，不自动修复控制器。
2. 当前最新模型与实测控制器角度直接对应。新实例替换原 J2/J3/J5 反号边界，读写都使用同一物理角约定。原入口的约定不改。启动时和每次发运动前，模型 FK 与控制器位姿须在 0.5 mm、0.003 rad 内，否则拒绝运动。单姿态检查不能证明所有姿态的符号约定，运动验收仍需现场完成。
3. 按控制器实际配置的工具偏移检查 TCP，不再把法兰位姿当作 EG2 夹持点。当前 Arm_Tip 零偏移，因此控制参考是法兰；固定腕部方向时，整个工具随法兰平移。图中 EG2 只代表模型，不证明真实工具几何与它一致。
4. 不再要求额外输入 pico arm。有效数据/朝向就绪后，先松开 Grip 与扳机至少 0.3 秒，再按住 Grip 允许低速平移；按着 Grip 启动不会自动跟随。松开 Grip 请求保持并撤销本次启用，追踪断流后必须重新设置前方和松握。
5. 不套用旧的 z≤0.65 m 示例盒。默认改为启动实测位置为中心的 **3 cm 球形试运行边界**，整次进程固定，反复松握不能移动边界。默认速度 0.01 m/s、倍率 0.3，腕部方向锁定，夹爪禁用。此球不是已确认无障碍空间，也没有全臂碰撞检测。
6. 修正旧测量对象被镜像线程重复发布时会刷新反馈时间的问题：只有新解码的网络样本可刷新时间戳。超时、跟随偏差、IK 无有效进展等不会伪装成功。
7. 原运行保护、独立守护与停止流程保留；Windows PID 查询仍用只读接口。CLI stop 不会被遥操写入互斥拦住。复用已有 PC Service 时不会结束非本启动器创建的服务。

## 启动

先松开手柄 Grip、扳机。真实机械臂必须静止、运动区域无人且无障碍，专人在现场能立即使用柜体急停。

```powershell
Set-Location E:\SDG-VLA\RM65_PICO
.\start_real.bat -Check     # 完全离线：模型/配置
.\start_real.bat -Inspect   # 只读连接实机并做静态 FK 检查；不启动 SDK/守护/运动
```

完成现场核对后，由操作者启动：

```powershell
.\start_real.bat
```

默认配置是 config/real_pico.example.json；若有 config/real_pico.local.json，则优先使用本地文件，**不会覆盖旧本地配置**。若沿用了旧版本地工作空间，仍可能被旧边界拦住，需要人工审查配置，不要盲目扩大。activation 可设为 cli 恢复人工 pico arm 模式；默认 grip。

PICO 与电脑通过局域网连接，头显里选择**电脑 IP**，不是机械臂 192.168.1.18。开启 Controller Tracking、Send；Head Tracking 可用则开启，不能用时可手动设前方。确认电脑端 tracking 计数持续增长；头显端 FPS 不是电脑收包证明。

松开 Grip，手柄水平指向前方，用拇指把左摇杆垂直按进手柄一下再松开。等待 READY，再按住 Grip，小幅单轴试动；松开请求保持。不需要输入 pico arm。启动或启用不会自动回零、去仿真 home、使能或清错。

原始原生 CLI 保留，但不要与 PICO 同时发其他运动命令；原 CLI 省略速度可能为 100%，不要把遥操的低速上限误当成原 CLI 全部指令的全局上限。

## 前方到底是 +X 还是 −X

这是操作者相对机器人底座的方向，控制器无法自动知道。默认仍明确标注 +X，不暗中猜测。只有现场确认后才选择：

```powershell
.\start_real.bat -Forward "+X"
# 若已确认操作者向前应对应底座 -X：
.\start_real.bat -Forward "-X"
```

也可在本地 JSON 设置 robot_forward。切换需先正常退出，再启动；不允许运动中突然翻转方向。

| 选择 | 向前 | 向右 | 向上 |
|---|---|---|---|
| +X | 底座 +X | 底座 −Y | 底座 +Z |
| −X | 底座 −X | 底座 +Y | 底座 +Z |

−X 是水平整体旋转 180°，不是单独反转 X 或关节符号。相机画面方向不代表底座方向。

## 停止与排查

- 松开 Grip：请求原通路退出透传并保持实测角，不承诺瞬时刹停。
- pico disarm：锁住自动启用；重新松开 Grip、按摇杆设前方后才解锁。pico off 停止 PICO 客户端。
- 正常退出用 quit。未退出的真机进程不会被启动器强杀；不要反复 Ctrl+C 或按旧 PID 杀进程。
- STOPPED、Hold unconfirmed、FK mismatch、反馈过期：不要通过放宽限值或反复启动强行运动；先确认真机静止，必要时物理急停，排查后恢复。
- 当前接近伸直：向上可能不可达，某些方向可能触发 IK 无进展。不会自动扳弯机器臂或回 home；需要有经验的人员用既有受控方式准备合适的非奇异初始姿态。
- collision stage=0：软件不会代替你设置保护等级；现场人员应按控制器安全说明检查硬件保护。未核实急停与停止距离前不要做大幅试动。

软件无安全认证，没有全臂/线缆/人员碰撞检测，网络中断、系统卡死时保护可能无法发送停止。必须使用物理隔离和硬件急停，不能无人值守。
