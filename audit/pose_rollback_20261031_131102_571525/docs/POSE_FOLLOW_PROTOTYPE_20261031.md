# 位置与姿态跟随：离线原型

原型尚未启用于本机实机配置。`wrist_mode` 默认 `position`，`feedback_seed` 默认 `false`；现有启动命令仍使用原模式。

- `wrist_mode: "pose"` 使用握持时的手柄和工具姿态作为相对参考，跟随平移和旋转。纯旋转超过 0.5 度也进入运动路径。单个追踪样本旋转跳变超过 45 度时停用跟随，要求释放 Grip。
- 姿态受角速度限制时，按当前帧限速后的姿态计算手腕目标，减少夹爪 TCP 绕腕部摆动。
- `feedback_seed: true` 使联网实时桥在握持期间每次求解前用新鲜的实体关节反馈重置仿真模型和 IK 种子。它只修改仿真数据，原有实体关节限速与反馈保护继续生效。

离线假反馈测试只能验证模型、数学和输入处理，不能证明实体控制性能、夹爪实际 TCP 标定、固件兼容或退出保持成功。回放旧实机数据也不能证明改变控制方式后的实体响应。

2026-10-31 的日志中，松手后曾有 `hold_confirmed`；退出时独立保护报告心跳超时，恢复命令未确认，退出后的只读状态为六轴使能且错误为零。心跳中断与保护恢复超时的根因尚未确定；在解决前不应把原型视为可投入实机使用的优化版本。
