# RM65 tabletop scene

Supported teleoperation scene: scene_gemini_gravcomp.xml (configured by the root launcher).
RM65-B, RMG24, Gemini335 with adapter; base mounted at table height 0.70 m.

The upright wooden block has a 0.05 x 0.05 m square top and 0.09 m height.
The open wooden receiving box has a 0.058 x 0.058 m inner opening.
The block starts outside the receiving box.

Run start.bat -Mode scene from the repository root. Other retained non-D435i
XML variants are source/reference assets, not the default teleoperation entry.

See the root README and docs/CONFIGURATION.md before changing the scene.
